# HTML コメントの説明文に、目印コメントや閉じ記号を書かない

**確認日**: 2026-09-02
**一次ソース**: gonin の本番トップページに説明文が漏れて表示された実測（gonin#18・PR #19）と、
HTML のコメント構文（`<!--` … `-->`・入れ子にできない）

---

## 事実

HTML のコメントは**入れ子にできない**。コメントの中に最初に現れた `-->` で、そのコメントは閉じる。

gonin では、雛形（`index.html`）の説明コメントに「カードは目印 `<!--POSTS:分類id-->` の位置に
差し込まれます」と、**目印そのものをコメント記法のまま**書いた。すると目印の `-->` で説明コメントが
途中で閉じ、**残りの説明文がトップページに素の文字として漏れた**。

自分の書いた注意書きに「-->」という文字列を入れても同じことが起きる（実際に2回目もそれで漏れた）。

## 対処

1. 説明文の中では目印を**記法なしで**書く（例:「目印（POSTS:分類id のコメント）の位置に」）
2. 「閉じ記号」「コメントの終わり」のように**言葉で書き**、`-->` の3文字を説明文に入れない
3. **関所で機械的に止める**＝コメントを全部取り除いた後に `-->` が残っていたら漏れている

```bash
# コメントを除去したあとに閉じ記号が残っていたら NG
perl -0777 -ne 's/<!--.*?-->//gs; exit(/-->/ ? 1 : 0)' public/index.html
```

gonin では `scripts/image-gate.sh` の `gate_markers` に入れ、`check.sh`（公開の直前）が毎回見る。

## なぜ関所が要るか

コメントの漏れは**見た目でしか分からず、書いた本人は気づきにくい**（説明を書いた直後は
コメントの中だと思い込んでいる）。テンプレートを関数が組み立てる構成では、生の雛形を
ブラウザで開く機会も減るので、機械で見るのがいちばん確実。
