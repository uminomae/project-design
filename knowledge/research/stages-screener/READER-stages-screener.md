# ものの見方の広さスクリーナー

**視座**・**メタ認知**・**インクルーシブ（包摂）**——どの視点から観ているか、何が観えているか、どこまでを含めて観ているか。ふだんの考え方のこの三つを、16問で確かめるスクリーナーです。いちばん奥の帯（6.0・6.5）では、**非二元性**——時間や境界に限られないものと日常とが二つに分かれていない見方——があるかどうかも見ています。
各問5つの選択肢から、ふだんの自分にいちばん近いものを1つ選びます。5分ほどで答えられます。

**こんな人に**：自分のものの見方を確かめてみたい人／意味や生き方、孤独や死といった実存的な課題に向き合っている人／これまでの見方が通じなくなったと感じている人／非二元性や瞑想・内省に関心がある人

## やってみると分かること

- **包摂の度合い**：考えるときに、どれだけの視点・人間関係・時間の幅を取り込んでいるか。
- **メタ認知の層**：考えている自分に気づいているか、さらに「気づいている自分」まで見えているか。
- **自分の経験に言葉と境界線がつく**：なんとなくやっていたことに名前がつき、似た経験どうしの違いを言い分けられるようになります。
- **余裕のなさに気づく目安になる**：いつもの自分の見方を知っておくと、ふだんより狭い基準で判断していると感じたときに、比べる目安になります。
- **すれ違いの理由を言葉にできる**：相手と自分が、違う範囲を見ながら話していたのかもしれない、と気づけます。
- **実存的な課題の手がかりになる**：自分の見方の広さに気づくこと自体が、意味や生き方をめぐる課題への直接の対策になる、というのが監修者（pjdhiro）の見立てです。確かめられた効果ではなく、気づきのきっかけとして置いています。

どの段階が良い・悪いということはありません。

## 始める前に

- これは**診断ではありません**。傾向をざっくり見るための、ゲームのような目安です。他人と比べたり、絶対的な段階を当てたりするものではありません。
- 一時的な体験ではなく、**ふだんの見方**に近いものを選んでください。
- 選ぶときに「以前の自分ならこっちを選んだだろう」と思い当たることがあれば、それも一つの発見です。
- 迷う問は飛ばせます。飛ばした問は採点に数えません。
- 回答はどこにも保存・送信されません。ページを閉じると消えます（ページの閲覧回数だけは計測しています）。

実存的な課題の中にいる人、これまでの見方が通じなくなった、意味が見えなくなったと感じている最中の人へ：下の帯の選択肢を選ぶことは、何かが欠けているという意味ではありません。どの帯も、次の見方へ移っていく途中の一つの場所です。

## 五つの帯

帯の名前と定義は、Terri O'Fallon の STAGES モデルの論文から借りています。下の五つは論文の記述を自分の言葉で要約したもので、原文はページ末尾の資料で読めます。
数字は段階を表す便宜上の記号です。

### 〜3.5　Achiever まで（正しさと目標の見方）

- **視座**: 3人称まで
- **何が観えているか（メタ認知）**: 考えや感情と、それが自分の行動にどう関わるかを振り返る
- **何を取り込むか（包摂）**: 正しいやり方、専門知識、目標、自分の役割
- **出典**: O p.28

### 4.0〜4.5　Pluralist〜Strategist（関係と仕組みを見渡す見方）

- **視座**: 4人称
- **何が観えているか（メタ認知）**: 考えている自分に気づく。「相手が自分をどう見ているか」にも気づく
- **何を取り込むか（包摂）**: 複数の視点、文脈、複雑な仕組み、人の成長の流れ
- **出典**: O p.29, B p.78

### 5.0〜5.5　Construct Aware〜Transpersonal（意味の作られ方に気づく見方）

- **視座**: 5人称
- **何が観えているか（メタ認知）**: 言葉や境界や意味を心が作っていると見える。気づきそのものに気づく
- **何を取り込むか（包摂）**: 意味づけの仕組み。時間や境界を超えたもの（ただし日常とは切り離されている）
- **出典**: O p.29, B p.73

### 6.0　Universal（時間や境界のなさと日常が分かれない見方）

- **視座**: 6人称
- **何が観えているか（メタ認知）**: 時間や境界に限られないものと、日常の現実が別々になっていない
- **何を取り込むか（包摂）**: 自分と相手の、気づいている意識そのものが響き合う全体
- **出典**: O p.29, B p.78

### 6.5　Illumined（すべての層を照らす見方）

- **視座**: 6人称
- **何が観えているか（メタ認知）**: 見ている場そのものから、体・考え・気づきの層が互いに入り込み合うところが見える
- **何を取り込むか（包摂）**: 物質・生命・心の進化の流れ全体。わずかな動きが全体に響く
- **出典**: O p.29, B p.79

- **視座**は、どの人称の視点から観ているかです。論文では、段階そのものが一つの視点として定義されています（O p.18）。ここで言う視座はふだんの見方のことで、一時的に入れ替わる「見る位置」とは別のものです（O p.22）。
- 受け取る → どちらかを選ぶ → 両方を見る → 互いに入り込み合う、という並びは、階層ごとに繰り返されます。階層で変わるのは、見ている対象です（O p.26, B p.101）。

## 段階のしくみ

段階は「**何を対象にできるか**」で分かれます。ある段階では、その中から観ていて自分では観えなかったものが、次の段階では対象として観えるようになります。前の段階は捨てずに、含んだまま広がります。論文は、これを「何人称の視点を取れるか」で数えています（O p.18）。ここでは人称の代わりに、何を対象にできるかで並べました。

### 12の段階の全体図

STAGES は 1.0 から 6.5 までの12段階を、**観ている対象の層**（具体・微細・メタの3つ）と、**その対象との関わり方**（4つ）の掛け合わせで組み立てています（O p.26, B p.101）。

| 対象の層 ＼ 関わり方 | 受け取る（そのまま取り込む） | 選ぶ（一方を選んで動かす） | 両方を見る（二つを並べて両立させる） | 入り込み合う（互いが互いを形づくる） |
|---|---|---|---|---|
| **メタ**（気づきそのもの・意味の作られ方） | **5.0** Construct Aware：言葉・境界・意味、自我も心が作っている | **5.5** Transpersonal：気づきそのもの。時間や境界を超えたもの（日常とは別） | **6.0** Universal：時間や境界のなさと日常が別々でない | **6.5** Illumined：体・考え・気づきの層と、気づいている意識が入り込み合う |
| **微細**（考え・感情・視点・仕組み） | **3.0** Expert：自分の考えと専門知識。正解は一つ | **3.5** Achiever：目標・成果・因果。考えを振り返り行動へ | **4.0** Pluralist：複数の視点と文脈。自分の見方も文脈の産物 | **4.5** Strategist：仕組み全体と自他の成長の道筋。自分もその一部 |
| **具体**（体・物・目の前の人・決まり） | **1.0** Impulsive：体の欲求と目の前の出来事 | **1.5** Egocentric：欲しいものを取りにいく。自他の区別 | **2.0** Rule-Oriented：決まりと、やりとりの公平さ | **2.5** Conformist：所属する集団の一員として形づくられる |

- **読む順**：具体の左端の 1.0 から右へ進み、右端まで来たら一つ上の層の左端へ。進むたびに、それまでの段階を含んだまま広がります。
- **同じ列には同じ関わり方が並びます**。右端の列はどの層でも「入り込み合う」です。2.5 は自分と集団が、4.5 は自分の内面と仕組みが、6.5 は気づいている意識とすべての層が入り込み合います。関わり方の型は同じで、含んでいる対象が層ごとに一段大きくなります。
- 同じ言葉でも、層が違えば含む範囲が変わります。たとえば「軌道」は、4.5 では自他の成長の道筋を、6.5 では物質・生命・心の進化を指します。
- このスクリーナーの帯は 3.0 からです。1.0〜2.5 は範囲外なので、確認は名前と大枠にとどめています。

### 段階ごとに、何を対象にできるか

| 段階 | 対象にできる（観えている） | まだその中から観ている（観えていない） |
|---|---|---|
| **1.0** Impulsive | 目の前の物と出来事 | 体の欲求と衝動 |
| **1.5** Egocentric | 自分の欲求（欲しいものを取りにいける）。自分と他人が別であること | 損か得かという物差し |
| **2.0** Rule-Oriented | 決まりと、やりとりの公平さ。相手から自分がどう観えるか | 決まりに従えば受け入れられる、という見方 |
| **2.5** Conformist | 自分の欲求、相手の気持ち | 所属する集団の決まりと関係（自分と集団の境目がぼやけている） |
| **3.0** Expert | 集団の決まり（離れて自分の声を持てる）。少し離れて観た自分 | 自分のやり方の正しさ、専門の基準（正解は一つ） |
| **3.5** Achiever | 自分の考えと行動のつながり、目標と結果、自分の信念の矛盾、5〜10年先 | 自分で選んだ価値観。客観的な正解があるという前提 |
| **4.0** Pluralist | 自分の価値観が育ちや文化で作られたこと。考えている自分。相手が自分をどう観ているか | 「どの見方も等しく正しい」という構え |
| **4.5** Strategist | 自分の意味づけの仕組み、仕組みどうしの関係、自他の成長の道筋。対立に自分も加わっていること | 意味づけをしている自分の物語。対話と検証で真理に近づけるという信念 |
| **5.0** Construct Aware | 言葉・境界・意味、自我も心が作っていること | 言葉と地図で理解しようとする構え |
| **5.5** Transpersonal | 自我が物語を作り続ける働き。気づきそのもの | 時間や境界を超えたものが、日常と切り離されている。観ていることが長続きしない（「わかっているのに、また」） |
| **6.0** Universal | 時間や境界に限られないものと日常の現実（別々でないものとして）。自分と相手の、気づいている意識が響き合う全体 | 観ている位置そのもの（6.5 で層の一つとして観えてくる） |
| **6.5** Illumined | 体・感情・考えの層と、それに気づいている意識そのものが入り込み合うところ。物質・生命・心の進化の流れ全体 | （データが少なく、書けない） |

- 左の列は、論文の定義を自分の言葉で短くまとめたものです（主に O pp.28–29。Cook-Greuter の段階の記述で補いました）。右の列は、次の段階で対象になるものを、同じ資料から読み取って書いたものです。
- 5.5 までは、対象にできるものが一段ずつ増えていきます。6.0・6.5 では、新しく何かを対象に加えるというより、分かれていたものが分かれなくなる形に変わります。6.0 では時間や境界のなさと日常が、6.5 では観ている意識と観られている層が、入り込み合います。6.0・6.5 の選択肢が非二元性を条件にしているのは、このためです。
- 7.0 はデータがなく、このスクリーナーにも選択肢を置いていないので、表に入れていません。

### 三つの軸とのつながり

- **視座**：誰の見方まで対象にできるか。相手 → 集団 → 仕組み → 文化、と広がります。
- **メタ認知**：自分の見方をどこまで対象にできるか。考え → 考えている自分 → 意味づけ → 意識そのもの、と深まります。
- **包摂**：対象にしたものを、どこまで含めて観ているか。

「何を対象にできるか」は、視座とメタ認知を一つの問いにまとめた言い方です。

## 知っておいてほしいこと

- **6.5 はデータが少ない段階です**。STAGES の検証研究では、統計的な結論が成り立つのは 2.0〜6.0 で、6.5 は確かな結論を出すにはデータが足りないとされています（V p.55）。6.5 の選択肢は、論文の短い記述から広げて書いた部分がいちばん多くなっています。
- **5.0〜6.0 の人も 4.0〜4.5 の答えを多く選ぶ可能性があります**。検証研究では、5.0〜6.0 の人の回答にも 4.5 と採点される内容が多く含まれていました（V pp.52–53）。一つの帯だけでなく、分布で見てください。
- **x.0 の段階の人は、一つ前の段階の答えを選びやすい**可能性があります。検証研究では、x.0 の段階の人は言葉が出にくく、一つ前の段階の内容に下がりやすいとされています（V p.53）。

## 何を借り、何を判断したか

- **借りたもの**：帯の名前と定義（論文の要約）。「段階のしくみ」の段階の記述の補い（Cook-Greuter の要約）。
- **LLM と監修者が判断したもの**：16 の問い、各選択肢の文、各選択肢がどの帯に当たるか。「段階のしくみ」の表の右の列（次の段階で対象になるものの読み取り）。
- **求めている正確さ**：各選択肢が、借りた定義と合っていること（内容の妥当性）まで。同じ人が何度答えても同じ結果になるか、STAGES の正式な測定（訓練を受けた採点者による文章完成法）と一致するかは確かめていません。
- 論文の全文や長い引用は載せていません。原文は下の資料で、無料で読めます。
