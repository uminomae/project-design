## 3. 執筆ルール（公開ページの書き方）— 破ってはいけない

原点セッションの pjdhiro 指示から抽出。

1. **一人称の語り**: 「私の体験」「私の問い」。体験→問いの順（素朴体験があった、だから問いが生まれた）
2. **三点セット**: 数学の定義を出すたびに ①**点と線**（人と人の間を点と線で）②**現実世界のたとえ** ③**もしも人間関係でいうなら** の3つを添えて噛み砕く。「1つ1つをゆっくり。長文になっても構わない」
3. **視覚化**: 三つ組・閉じる・ファノ・ハゲ球（つむじ）は必ず図（自己完結 SVG）で。「読者が比喩や直感を飛ばせるように」
4. **表で整理**: 3と7以外の諸問題（乗除ルール・支配定理）は表に
5. **anti-collapse**（notes/README 由来）: 抽象ラベル（定理名・記号）に畳んで終わらせない。felt な像（回す・じゃんけん・つむじ・織物）を主役に
6. **棄却の書き方**（pd#115 で確立・メモリ [[public-explanation-metaphor]]）: 「棄却」を書くときは必ず **三層段差表**（数学=定理/強い読み=棄却/弱い読み=存続）＋**日常比喩**（アーチとモルタル／関数電卓で足し算しか押していない 等）をセットにする
7. **誠実さを売りにする**: 「仮説は縮んだのではない。何でも説明する物語から、外れうる予測を持つ仮説に変わった」。うまくいかなかった部分も §9 に正直に書く
8. **デザイン**: DESIGN-RULES §0a 必須制約（サイト VI 継承。独自テーマ新造禁止）。詳細は `reader/README.md`
