## 問い

可除代数‑意識/組織仮説（pd#115 / CN-010）のどこが**定理**で、どこが**対応の措定**で、どこが**数秘（numerology）**か。特に「チームは7が上限」は八元数（𝕆）由来か、単に認知資源（作業記憶）由来か。本 RR は本プログラムの epistemic gate（調査軸④）の分析枠と現時点の判定を成文化する。

## 方法 — 二つの道具

### 道具1: 三層分解 T / M / N

| 層 | 内容 | 判定基準 |
|---|---|---|
| **T（定理）** | 数学内部で確定した主張 | 証明が存在する（RR-001 が成文化中） |
| **M（対応措定）** | 現実の系を数学構造へ写す賭け | 公理が現実で**操作的に**成立しているか検証可能な形で書けるか |
| **N（数秘）** | 数の一致だけを根拠にした飛躍 | 構造（演算・公理）が現実側で仕事をしていない |

**M と N の境界線 = 遊休構造基準（idle structure criterion）**:
数学構造が説明力を持つのは、その**公理と演算が現実側で対応物を持ち、実際に仕事をしている**範囲のみ。使われていない公理は装飾であり、「次元の数が合う」だけの対応は N に転落する。
[P] これは科学哲学で標準的な要請（構造的説明 vs 単なるアナロジー）。

### 道具2: 二系統の峻別

「3がベスト・7が上限」を説明しうる系統は二つあり、**予測が異なる**。

| | **A系: ペア数 `n(n-1)/2`** | **B系: 虚単位梯子 1, 3, 7** |
|---|---|---|
| 数学的実体 | 組合せ論 C(n,2)。so(n) の次元でもある | 可除代数 ℝ,ℂ,ℍ,𝕆 の虚部次元（Bott–Milnor/Kervaire） |
| 上限の性格 | **外部パラメタ依存**（認知容量・調整技術との比較で閾値が決まる） | **構造内在**（p∈{0,1,3,7} 以外は零因子必発） |
| 劣化の形 | **滑らかな逓減**（Ringelmann 型 process loss） | **硬い崖**（4,5,6 人は圏論的に「割れない」） |
| 禁止人数 | なし（コストが増えるだけ） | あり（p=2,4,5,6 と ≥8） |
| ツールの効果 | 調整技術が進めば上限は**動く** | 上限は**動かない** |

## 中心的発見 — 判別可能点は 3 ではなく 7

### n=3 では A と B は数値的に一致し、判別不能

[P] 3人のとき: ペア数 C(3,2)=3 ＝ 虚単位数 |Im ℍ|=3 ＝ dim so(3)=3。さらに Im ℍ の外積は so(3) のリー括弧と同型。**3人チームでは A 系と B 系は文字通り同じ構造を指す**ため、3の現象からは両者を判別できない。

### n=7 で初めて乖離する

[P] 7人のとき、両系統は数も構造も分かれる:

- **A系**: ペア数 C(7,2)=**21**。関係の全体は so(7)（21次元、リー代数＝結合的な世界の無限小版）。
- **B系**: 虚単位 **7** 本。ペアの積構造は **Fano 平面 S(2,3,7)** — 7つの**三つ組**（線）に組織化され、対称性は G₂（**14**次元）⊂ SO(7)。7次元外積は Jacobi 恒等式を満たさず、so(7) の括弧**ではない**。

つまり A は「7人の実体は21本のペア」と言い、B は「7人の実体は**7つの三人組**」と言う。ここが本仮説の生死を分ける観測点になる。

### B系の生成的予測（遊休構造基準を通過する部分）

[S] 八元数の積表（Fano 平面）を組織に写像すると、単なる「7という数の一致」を超えた**構造的予測**が出る:

1. **三つ組分解**: 機能する7人組織の調整単位は21のペアではなく**7つの重なり合う3人細胞**である。
2. **ホーム三つ組の一意性**: S(2,3,7) の定義より、**どのペアもちょうど1つの三人細胞に属す**（関係の帰属が一意）。
3. **各人3細胞**: 各メンバーは**ちょうど3つの細胞**に属す（Fano の各点は3線上）。
4. **細胞内は結合的・細胞間は非結合的**: Fano の1本の線が生成する部分代数は ℍ（結合的）。よって**細胞内の調整は段取りの順序に依存しない**が、細胞をまたぐ調整は**括弧の切り方（誰経由で先に通すか）で結果が変わる**。7人組織が「工程を一列に平坦化できない」の精密化。

これらは A 系からは出ない。**逆に、7人組織がペア管理の滑らかなコスト増しか示さず、三つ組構造が観測されないなら、Fano 対応は装飾（N）と判定する**。

## 対抗仮説 — A系＋認知資源による deflationary 説明

[S] 代数を使わずに 3 と 7 を出す経路が存在する:

- **3最適**: 全ペアの相互透明性（全員が全関係を把握）が成立するのは C(n,2) ≤ 4（Cowan の作業記憶容量 4±1）まで、すなわち **n=3**（3ペア）が最大。n=4 で 6 ペアとなり超過。
- **7上限**: 各人が追跡する相手は n−1。**n=7 で 6 ≈ Miller の 7±2 の下限**に達する。

ただしこの導出は **3 と 7 に別々の容量指標（Cowan 4 / Miller 7）を使い分けており、それ自体アドホック**。数秘への転落リスクは A 系にも対称的に存在することを明記する。どちらの陣営も「数が合う」だけでは勝てない。

## 「意識＝ℂ」「価値＝閉じ」は生成的か空虚か

| 措定 | 空虚になる条件 | 生成的になる条件 |
|---|---|---|
| 意識＝ℂ | ℂ を **ℝ²（ただの平面）としてしか使わない**なら circumplex（Russell の valence×arousal）で足り、体の構造は遊休 → 空虚 | **積・除が仕事をする**場面を特定できたとき。例: 状態の合成＝回転伸縮（位相の加算・強度の乗算）、`i` 倍＝「物質を精神へ回す90度」が操作的に対応物を持つ、割り算＝関係の解消が定義できる |
| 価値＝閉じ | 「閉じ」が結果論的ラベル（うまくいった＝閉じた）なら反証不能 → 空虚 | **零因子の操作的対応物**（非ゼロ×非ゼロ＝ゼロ：どちらも生きているのに関係として解決不能になる組）を事前に定義・観測できたとき |

現時点の判定: **両措定とも M 層に留まっているが、空虚側に落ちる危険が具体的に特定できた**。次の作業は「積が仕事をする場面」と「零因子の対応物」の操作的定義（#116 と連携）。

| F4 | 物質⊥精神の直交が実証で崩れる（CN-009 の非可換相補が優勢） | 個は ℂ でなく ℍ 寄り。梯子の段づけ全体を再割当て（個=ℍ なら組織=𝕆 のみ、上限は7の一段のみになる） |

## B系の救済路（撤退線の事前整理）

反証時にどこまで退けるかを先に決めておく（後出しの免疫化を防ぐ）:

1. **記述法則 → 設計原理**: 「3と7**しか存在しない**」（記述）ではなく「3と7を選べば**閉じたまま拡張できる**」（規範・アーキテクチャ選択）。5人チームの存在は反証にならないが、主張は大幅に弱まる。
2. **人数 → 自由度**: 虚方向＝人ではなく「共有注意の自由度」「役割」なら、人数との数の一致は要求されなくなる。ただし操作的定義の負担が増す。
3. **入れ子読み**: 個(ℂ) ⊂ 3人細胞(ℍ) ⊂ 7細胞組織(𝕆) の**階層設計原理**として読む。Fano の三つ組分解と整合的で、救済路1と両立。
