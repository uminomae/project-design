## 1. Q9a — アコーディオン解説草案「複素平面2枚の直交した束」

> 📖 **「複素平面2枚の直交した束」とは** — まず、なぜこれが**絵に描けない**かから正直に言う。
>
> 複素数は1枚の平面だった（実軸1本＋虚軸 `i`）。四元数の軸は4本（1, i, j, k）で、これは**2枚の平面の束**に分けられる: {1, i} が張る1枚目と、{j, k} が張る2枚目。どの四元数も
>
> ```
> (a + bi) + (c + di)·j
> ```
>
> ——「1枚目の複素数」＋「2枚目の複素数 × j」の形に一意に書ける（ℍ ＝ ℂ ⊕ ℂj）。
>
> **「直交」の意味**: 2枚目の平面は、1枚目の**どの方向とも直角**で、共有するのは原点（0）ただ一点。——ここが絵に描けない場所だ。私たちの3次元では、原点を通る2枚の平面は**必ず線で交わる**（床と壁は必ず「角の線」を共有する）。「点だけで交わる直角な2枚」は、**4次元で初めて可能**になる。だから正しい絵は存在しない。図の代わりに、掛け算の規則（`i·j = k` など）で扱う——規則は4次元でも狂わない。
>
> **j の役割**: 1枚目の平面の中で `i` は「面内の90度」だった。`j` は 1 とも `i` とも直角——**面の外へ立ち上がる直角**だ。`k = i·j` はその合成。
>
> **2枚が「ただ並んでいる」のではない証拠**: `j` を通すと1枚目の複素数は共役に裏返る——`z·j = j·z̄`（例: `(a+bi)·j = j·(a−bi)`。`i·j = k`, `j·i = −k` から手で確かめられる）。2枚は編まれていて、行き来のたびに向きの反転を伴う。

読み候補（判定待ちのまま維持）: 二人の平面（ℂ）に対し、第三の人は「平面の外への直角」を持ち込む。面の中でいくら回っても出られない反転（Q5）に、面の外への軸が抜け道を作る。

## 2. Q9b — 本質の再抽出: 挟み込みは計算上の影、本質は「場の保全」

pjdhiro の疑い（挟み込み＝数式の都合であって現象の本質か?）を機械検証で検査した。結果、**疑いは正しかった**。表現（四元数でもパウリ行列でも同じ形になる）に依らない不変な内容は「挟み込み」ではなく、次の2つ。

### E1 — 場の保全（機械検証 1）

状況 v（純虚＝実部0のベクトル）に対して:

- **片側の作用 `qv`**: 実部が生じる——**答えが「場」（実軸＝全員が共有するリアルな場、Q9 採用の読み）に漏れる**。もはや純粋な「状況」ではない。
- **挟み込み `q v q⁻¹`**: 実部は厳密に 0 のまま。**場は無傷**で、状況だけが回り、大きさ |v| も保存される。

現象の言葉にすると: **働きかけっぱなしの関わりは、状況を回すだけでなく、場そのものに漏れ込む。場を無傷に保つ形の作用だけが「純粋な回転」になる**——それを数式で書くと、たまたま挟み込みの形になる。「往復・受け取り直し」は本質ではなく、**場の保全という本質の計算上の影**。

### E2 — 担い手と出来事の二層（機械検証 2）

変換のされ方が違う2つの層がある:

- **出来事の層**（挟み込みで変わる）: q と −q の区別が**ない**（`qvq⁻¹ = (−q)v(−q)⁻¹`）。
- **担い手の層**（片側で変わる）: q と −q の区別が**ある**（`qψ ≠ (−q)ψ`）。

±の記憶は担い手の層にだけ住む——これが Q9d（720度）の入口でもある。二つの層を混同すると Q9d の誤解が始まる。

### 読み候補 v2（判定待ち）

> 関わりの本質は、一方向の働きかけではない。**共有する場を無傷に保ったまま状況を回せる形の作用**だけが、純粋な回転として成立する。一方向だけの作用は、必ず場に漏れる——状況を変えたつもりで、場（全員が共有する現実そのもの）を汚している。

（旧候補「働きかけて、受け取り直す往復」は、この v2 の影の描写として降格。READER 既存コラム §「挟んで回す」の表現も判定後に差し替える）

## 3. Q9c — アコーディオン解説草案「パウリ行列」

> 📖 **「パウリ行列」とは** — 量子力学で、電子のスピン（自転のような向き）を **3つの直交する向きで測る**ための、2×2 の小さな行列3つ（σx, σy, σz）。
>
> 行列と聞くと身構えるが、正体は「**掛け算の規則を数字の表にしたもの**」だ。そして計算すると、
>
> ```
> i ↔ −iσx,   j ↔ −iσy,   k ↔ −iσz
> ```
>
> と置き換えたとき、掛け算の規則が**四元数とぴったり一致**する（`(−iσx)(−iσy) = −iσz` は `i·j = k` と同じ。機械検証可能）。
>
> つまり、**四元数とパウリ行列は、同じ機械の二つの筐体**だ。見た目（数の束／行列）が違っても、掛け算表——機械の設計図——が同じなら、同じ機械。
>
> ここから出てくる読み替えが面白い。パウリ行列の世界では、i, j, k は「3人の軸」ではなく「**3つの測る向き**」。そして σxσy ≠ σyσx——**測る順序を替えると結果が変わる**（非可換）。§3 で見た「A の軸を先に通すか B の軸を先に通すかで向きが逆になる」は、量子の言葉では「測り方の順序が効く」と同じ形をしている。

読み候補（判定待ちのまま維持）: 虚軸3本 ＝ 非可換な「切り口」3本。CN-009（切り口＝非可換な観測量）とここで合流する: 3人チーム＝三つの相補的な切り口が閉じて割れる系。

## 4. Q9d — 720度の正確な形: 誤解の一覧を先に固定する

pjdhiro の警告（「おかしい世界。誤解したまま私も進めそう。とてもとても注意」）を受けて、**採否の判定より先に、誤解と正確な形を固定する**。

### 誤解の一覧（✕）と正確な形（○）

| | 言明 | 判定 |
|---|---|---|
| ✕ | 「四元数の世界では、物が360度回っても元に戻らない」 | **誤り**。状況（ベクトル・出来事の層）は360度で**完全に戻る**（機械検証 3: `qvq⁻¹ = v`）。戻らないのは**担い手の層**（片側で変換されるもの）だけ |
| ✕ | 「戻らないスパイラル（永遠に累積するねじれ）」 | **誤り**。ねじれの記憶は **±1 の2値**であり、**ちょうど二周で完全に閉じる**。三周目は一周目と同じ。累積しない |
| ✕ | 「−1 は観測できる劣化・損失」 | **誤り**。−ψ は単独では ψ と**区別がつかない**（大きさも向きの効果も同じ）。−1 が現れるのは**比較・干渉**——他と重ね合わせたときだけ |
| ○ | 正確な形 | **一周で、出来事は元に戻って見える。だが、回した担い手と場のつなぎには裏返り（−1）が残っている——単独では見えず、比較したときだけ現れる形で。もう一周して初めて、つなぎまで完全に解ける** |

### 体で確かめられる実演（ディラックのベルトトリック）

この「おかしい世界」は、実は日常の物体で再現できる。帯（ベルト）の一端を固定し、他端に本を挟む:

1. 本を **360度**回す → 本は元の向きに戻るが、**帯にはねじれが残る**。本を回さずに帯を動かすだけでは、このねじれは**絶対に解けない**。
2. さらに **360度**（計720度）回す → 帯のねじれは、本を回さずに帯をたぐるだけで**完全に解ける**。

「本」が出来事（360度で戻って見える）、「帯」が担い手と場のつなぎ（一周分の裏返りを記憶する）。おかしいのは世界ではなく、**「向き」だけ見て「つなぎ」を見ていなかった**私たちの目のほうだ、という言い方もできる。

### 読み候補の修正（v2・判定待ち）

旧候補「循環ではなく、戻らないスパイラル」は上の表のとおり**不正確**（永遠に戻らないわけではない。二周で閉じる）。修正:

> 一周は、閉じて見える。だが担い手と場のつなぎには、単独では見えない裏返りが残っている。**二周して初めて、本当に閉じる。**

CN-009「止揚を伴うスパイラル」との対応は、この限定付きの形（**一周では閉じきらない／ねじれは比較でだけ見える／二周で閉じる**）でのみ検討する。「戻らないスパイラル」という語での対応付けは取り下げ。
