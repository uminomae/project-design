# CN-012: 「未マージ」は「未回収」を意味しない — 並行エージェント環境でのブランチ照合

## なぜこのノートがあるか

複数の Claude セッションが**同時に同じリポジトリを触る**運用（worktree ＋ `claude/*` ブランチ）では、
ブランチが数十本単位で溜まる。**溜まったブランチを整理するとき、「未マージ＝まだ回収していない成果」
と読むのが自然だが、これは誤り**である。

実測: **未マージ7本のうち5本は、本流がすでに同内容以上を持っていた**（回収が要ったのは3点だけ）。
この非対称性は偶然ではなく、並行エージェント環境の**構造**から出る。

---

## 1. なぜ「未マージ ≠ 未回収」になるのか

並行セッションは**同じ現実を観測して、それぞれ独立に記録する**。したがって同じ事実が
複数のブランチに別々の文言で書かれ、**先に本流へ入った方だけが残る**。後発のブランチは
「未マージ」のまま残るが、**中身はすでに本流にある**。

さらに3つの経路で「未マージだが回収済み」が生まれる:

| 経路 | 中身 |
|---|---|
| **並行記録** | 別セッションが同じ事実を別ブランチで本流へ入れた |
| **人手による復旧** | 記録喪失に気づいた後続セッションが、内容だけを書き直して本流へ入れた（**採番・文言が変わるので機械照合が効かない**） |
| **後の判断による上書き** | ブランチの決定が、その後の新事実で覆された（例: 「堆肥を軽く入れる」→ 堆肥が無いと判明し「無施肥で播く」に変更） |

**帰結**: **ブランチ名・コミット日・マージ状態のいずれも、回収済みかどうかを判定しない。**
判定できるのは**本流側の中身**だけ。

---

## 2. 照合の2つの罠（どちらも実際に踏んだ）

### 罠A: `git diff A...B` は merge-base 基準

3点 diff は **merge-base(A,B) → B** の差分なので、**A（本流）が独自に同じ内容を獲得していても
「B の追加」として出る**。分岐が古いほど誤検出が増える。

> **回避**: 2点 diff（`git diff A..B`）と、**実ファイルへの grep** で裏を取る。
> ただし2点 diff は「本流が先に進んだぶん」が大量の削除として出て読みにくいので、
> **最終判定は「そのブランチ固有の文字列が本流に存在するか」の grep** に置く。

### 罠B: 表記ゆれが grep を素通りさせる

同じ概念を別セッションが別表記で書く（実例: ブランチ `刈り草` / 本流 `刈草`）。
**grep が 0 件を返したので「知見が失われている」と判定しかけた**が、実際には本流の方が
はるかに詳細な記述を持っていた。

> **回避**: **「無い」と出たら言い換えを最低1つ試す**（送り仮名・漢字/カナ・略記）。
> 0 件は「無い」ではなく「その表記では無い」としか言っていない。

---

## 3. 非対称性: 文書は再報告で復旧できるが、コードは復旧できない

今回**唯一、全数照合でしか見つからなかったのは iOS アプリ**（693行、作成後1週間本流に未到達）だった。
一方、失われた観察ログは**本人が気づいて再報告する**ことで復旧していた。

| 種類 | 失われたとき | 復旧経路 |
|---|---|---|
| **観察・事実の記録** | 当事者が「あれを書いたはず」と気づく | **再報告で復旧できる**（内容は当事者の頭にある） |
| **コード・生成物** | **誰も気づかない**（作った本人＝別セッションはもう存在しない） | **全数照合しか無い** |

**帰結**: **成果物の種類によってマージの緊急度が違う。**
コードを書いた回は、記録以上に**その場で本流へマージする**。再報告という保険が効かない。

---

## 4. 運用への落とし込み

1. **消す前に、本流の中身と全数照合する**（ブランチ名・日付では判断しない）
2. **照合は grep を最終判定に置く**。3点 diff は当たりを付けるだけに使う
3. **grep の 0 件を信用しない**。言い換えを1つ試す
4. **コードを書いた回は即マージする**（文書より優先。再報告が効かないため）
5. **削除するときは SHA 台帳を残す**（myhome `docs/branch-archive.md` が実装例）。
   ただし**台帳は保険であって回収の代替ではない**——GitHub の GC とローカル reflog の期限（既定90日）で
   参照は失効する。**本当に要るものは削除前に本流へ入れる**
