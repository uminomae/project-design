# CN-010: 可除代数‑意識/組織仮説 — 個の意識(ℂ)と組織(ℍ/𝕆)は同一の可除代数の梯子

## 概念の核心

二つの素朴体験——(A) 何かを作るとき体を流れる**物質的/精神的**の二軸信号、(B) チームは**3がベスト・7が上限**——は、同一の数学構造（**可除代数の梯子** ℝ→ℂ→ℍ→𝕆）の別の段の現れである、という仮説。

- **個の意識 = 複素数 ℂ**（虚1本）: 物質軸 ⊥ 精神軸が張る平面。`z = 物質 + i·精神`、`|z|`=意識の強度、位相=物質/精神のバランス、虚単位 `i`=「物質を精神へ回す90度」。可換・結合・割れる＝調和的だが「第三者」が生まれず単独では創発なし。
- **組織 = 四元数 ℍ(3) / 八元数 𝕆(7)**: 他者と関わり虚方向が増える。だが「閉じて割れる（関係が解決・復元する）」を保つ限り、非自明に成立する集団は **3 と 7 のみ**。3は可換性を、7は結合性を代償に、その崖のふちに立つ。
- **組織設計とは、個の複素的意識を、閉じたまま多体へ拡張する操作**であり、その解が構造的に3と7に限られる。

## 前提（解釈の賭け・要検証）と 定理（硬い部分・確定）の分離

**前提**: ① 物質 ⊥ 精神　② 意識 = 複素数 ℂ　③ 価値 = 関係の「閉じ」（割れること）

**定理**:
- Frobenius(1878): 結合的実可除代数は ℝ,ℂ,ℍ のみ（結合律を要求→上限3）
- Hurwitz(1898): ノルム保存代数は ℝ,ℂ,ℍ,𝕆 のみ（ノルム保存→上限7）
- Bott–Milnor/Kervaire(1958): 有限次元実可除代数は次元 1,2,4,8 のみ（他次元は零因子必発）
- Adams(1958–60): 平行化可能な球面は S⁰,S¹,S³,S⁷ のみ（＝ハゲ球で「梳ける」球）
- 外積の定理(Eckmann/Massey): ベクトル積が閉じるのは3次元と7次元のみ
- Fano = Steiner S(2,3,7)、Aut(Fano)=PSL(2,7)(位数168)、Aut(𝕆)=G₂

## 帰結

- 「者」の数 p（虚方向）に許されるのは **p ∈ {0,1,3,7}** のみ。p=2,4,5,6 と ≥8 は零因子で崩れ、割り算（＝解決）ができない。
- 個(ℂ)と組織(ℍ/𝕆)は同一梯子の別段。個→組織は「可換性→結合性」を順に手放す過程。
- 7人組織が「工程を一列に平坦化できない」のは気分でなく**非結合性の帰結**。リーダーは中心（ハブ）でなく**向き付け（符号規約）**。

## 中心的緊張（急いで解かない・pd#115 最重要課題）

**CN-009** は物質的/精神的な2つの切り口を「**直交軸ではなく相補的射影（非可換な観測量に近い）**」とし四象限を棄却している。本仮説の前提①「物質⊥精神→ℂ」と正面から緊張する。

- もし2軸が**直交**なら → 個の意識は **ℂ**（可換）。
- もし2軸が**非可換な相補**なら → 個の意識は既に **ℍ 寄り**（非可換）。

「直交(ℂ) か 非可換相補(ℍ的) か」の裁定が、個の意識モデルの形を決める。dual-aspect / Pauli–Jung 予想（心物中立的実在からの相補的分岐）とも接続。

## 保持論点（開いたまま・RR-002 で分析枠確定 2026-07-02）

- 「7上限」の二系統（A: ペア数 n(n-1)/2 ／ B: 虚単位梯子 1,3,7）は**未裁定**だが、RR-002 で判別枠が確定:
  - **n=3 では判別不能**（3 = C(3,2) = |Im ℍ| = dim so(3) で両系統が一致）。**判別点は 7**。
  - **B の生成的予測（Fano 三つ組）**: 機能する7人組織は 21 ペアでなく **7つの重なり合う3人細胞**に組織化され、どのペアもちょうど1つのホーム細胞を持ち、各人はちょうど3細胞に属し、**細胞内は順序不問（結合的=ℍ）・細胞間は段取り依存（非結合的）**。観測されなければ Fano 対応は数秘と判定する。
  - 対抗仮説（A+認知資源: 3最適=C(n,2)≤Cowan 4、7上限=n−1≈Miller）も**別々の容量指標を使い分けるアドホックさ**を抱える。数秘リスクは両陣営に対称。
- 「意識＝複素数」「価値＝関係の閉じ」の空虚化条件を RR-002 で特定: ℂ を ℝ² としてしか使わないなら circumplex で足りる（積・除が仕事をする場面の操作的定義が必要 →#116）。「閉じ」が結果論なら反証不能（零因子の対応物の事前定義が必要）。
  - **RR-004（軸②・2026-07-02）による裁定**: 意識＝ℂ の空虚リスクは circumplex に関する限り **confirm**。**ℝ²-polar の層（半径=強度・角度=種類）は強く接地**するが、**ℂ-field 固有の構造（積・除・`i²=−1`）は遊休**（Posner/Russell/Peterson 2005 は感情を二次元の「線形結合」＝ℝ² ベクトル空間で記述。梯子を駆動するノルム保存・除法・零因子不在は個の意識レベルで一つも仕事をしていない）。回転 U(1) だけが faint な例外だが ℝ² と共有の構造で乗法的閉包ではない。
  - **前提①の再評価（RR-004）**: circumplex の直交対は **valence×arousal** であって **物質×精神ではない**。前提①は circumplex から直接の裏づけを得られず、物質/精神への対応は未接地の追加措定。
- falsifier（RR-002 で具体化、RR-003・RR-004 で一部裁定 2026-07-02）:

  - F2 ツールで上限が動く→認知資源由来（未裁定）。
