# notes/

pjdhiro の **雑感メモ・気づきのログ** を集める場所。

## 存在理由（このディレクトリは何のためにあるか）

ここは発表物ではない。ブログでも SNS でもない。
どこかで誰かのために記したものではあるかもしれないが、目的はそこにない。

**目的は、pjdhiro と LLM が、pjdhiro の思考・価値観・視点を理解するためのコーパスを育てること。**

- 何に **気づき**、何を **問い**、何を **見つけた** のか——その記録を一次のまま残す
- 一篇ずつは小さな雑感にすぎない。だが **集まること**で、思考の癖・繰り返し現れる主題・
  価値観の重心が立ち上がる
- そこから **間接的に見えてくる「隠れたもの」** を探す。本人が明示していない前提、
  まだ言葉になっていない関心の軸、問いの背後にある問い——それを後から（LLM とともに）掘り当てる

> 群盲象を評す。一篇は象の一部に触れた手の感触にすぎないが、重なれば輪郭が浮かぶ。

## 運用ポリシー

- **発表用ではない**。論として整っていなくてよい。雑でよい
- 一次の語りを **改変しない**。原文をそのまま `## 原文` に保存する
- **解釈・体系化を急がない**（CLAUDE.md 絶対原則「保持論点を急いで解くな」）。
  気づいたこと・問いは、問いのまま残してよい
- 後から振り返るための軽いタグや「接点（仮）」は付けてよいが、断定しない（`[S]` 推測の温度）
- 1 篇 1 ファイル。命名: `{YYYY-MM-DD}-{slug}.md`
- front matter に最低限のメタ（日付・出典・テーマタグ）を置く

## LLM への読み方の指示

このディレクトリを読むとき、LLM は「正しい結論」を急いで出さない。
pjdhiro が **何を見ているか・どの軸で世界を切っているか** を観察し、
複数篇にまたがって反復する主題・対比・比喩を拾い、
本人がまだ名づけていないものに（仮の）名前を差し出す。それがこの器の使い方である。
