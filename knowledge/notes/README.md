# notes/

pjdhiro の **雑感メモ・気づきのログ** を集める場所。

## 構造（全体像）— 何がどこにあり、各々なぜ在るか

ディレクトリ名・ファイル名だけでは伝わらない **存在理由** を明示する。

```
knowledge/notes/
├── README.md                ← この器の取扱説明書（四目的・運用・読み方・構造）
├── OVERVIEW.md              ← 重ね合わせの「素材層」
├── SYNTHESIS.md             ← 現時点の仮案「全体像層」（always-latest）
├── {YYYY-MM-DD}-{slug}.md   ← エッセイ本体（pjdhiro 一人称・原文保存）
└── dialogue/                ← LLM対話録（参照用・エッセイとは別レイヤー）
    ├── README.md
    └── {YYYY-MM-DD}-{slug}.md
```

| パス | 種別 | 存在理由（名前だけでは分からない意味） |
|---|---|---|
| `notes/` | ディレクトリ | 単なる「メモ帳」ではない。pjdhiro の思考を理解し（A）、論に畳むと消える喩え・とっかかりを保存し（B）、物語的伝達物を創り（C）、全体像を掴んで畳む（D）——**四目的を持つ探究の器**。下記「存在理由」参照 |
| `README.md` | 取説 | 四目的・運用ポリシー・LLM への読み方（anti-collapse 禁則）・この構造表。**最初に読む** |
| `OVERVIEW.md` | 素材層 | エッセイ × 論（cs/as/ks）の **重ね合わせ**を可視化する層。各篇の要約、横断する主題・喩えのカタログ、保持論点（＝伏線）。洞察はすべて仮 |
| `SYNTHESIS.md` | 仮案層 | **現時点の全体像の見当**を常に最新に保つ生きた一枚（always-latest）。仮説×論文×エッセイ×対話録の重ね合わせから立てた「仮の底」と伏線台帳。目的D の準備層。**確定（pjdhiro 明示）と仮（見当）を分けて書く** |
| `{date}-{slug}.md`（直下） | エッセイ | pjdhiro の **一人称・原文保存**の雑感。改変しない。`## 喩えとしての価値` と `## 接点（仮）` を添える |
| `dialogue/` | 参照層 | pjdhiro ↔ LLM の **共構築の対話録**。エッセイ（一人称・原文）とは性質が違う（要点圧縮・話者明示・参照用）ので**別ディレクトリ**に隔離。重ね合わせを支える材料。Claude 発話は untrusted 寄りに扱う |

> 三つのメタファイル（README / OVERVIEW / SYNTHESIS）は **層**になっている：
> 取説（README）→ 素材を並べる（OVERVIEW）→ 全体像を立てる（SYNTHESIS）。
> エッセイ（直下）と対話録（dialogue/）は、その層に流し込む **一次素材と参照素材**。

## 存在理由（このディレクトリは何のためにあるか）

ここは発表物ではない。ブログでも SNS でもない。
どこかで誰かのために記したものではあるかもしれないが、目的はそこにない。

**目的は四つ。**

**目的A（コーパス）**: pjdhiro と LLM が、pjdhiro の思考・価値観・視点を理解するための土壌を育てる。

- 何に **気づき**、何を **問い**、何を **見つけた** のか——その記録を一次のまま残す
- 一篇ずつは小さな雑感にすぎない。だが **集まること**で、思考の癖・繰り返し現れる主題・
  価値観の重心が立ち上がる
- そこから **間接的に見えてくる「隠れたもの」** を探す

**目的B（とっかかり・喩え・気づきの誘発）← これがエッセイを残す主たる動機**:
抽象概念は **論だけでも理解できる**。「対立と止揚だ」「直交基底だ」と言えばそれまで。
だがそれでは**伝わらない・腑に落ちない**。エッセイの価値は、論に畳むと消えてしまう側にある：

- **初学者のとっかかり**（複素平面なしに虚数に触れる／ヘーゲルの止揚に音楽と腸から入る）
- **わかりやすい喩え**（−1の半分＝90度回す数 ＝ i／回しても崩れない丸い雲／風のように包む）
- **哲学・数学用語の素朴な概念理解**（止揚を「分断と侵略の袋小路 ↔ 包む」で体感する）
- **気づきの誘発**——言い切らずに「あ、そういうことか」を起こす余白を残す

**目的C（物語的な伝達物の創作）← 目的B の先にある創作のゴール**:
エッセイ（体験・喩え）と論（cs/as/ks の理論）を **重ね合わせる** と、
本質的で重要な主題が浮かび上がる。その主題に対して、
**ゆっくりと、素朴な体験だけで理解できる、物語のような伝え方の作品**を作る。**絵・図・比喩**を用いて。

- **重ね合わせ**：エッセイ（目的B の手触り）× 論（cs/as/ks の接地）→ 立ち上がる本質的主題
- **伝え方**：理屈で説明しない。**急がない**。素朴な体験・物語・絵図・比喩で、手触りのまま運ぶ
- **宛先**：初学者・将来の読者・娘（第一篇「小学生の娘にもわかるように」の問いを引き継ぐ）。
  PD wiki の「高校生向けのやさしい解説」と同じ精神の、さらに物語寄りの作品
- **位置づけ**：notes/ は**素材**、目的C の作品はそこから**派生する創作物**。
  最初の一作を作るとき、置き場所（例: `notes/tellings/`）と形式を改めて決める

**目的D（伏線回収的な統合・まとめ）← 全体像を掴んでから畳む総括**:
pjdhiro の論に **隠れた主題・本質・全体像** をまず見つける。その上で、
**後置再帰（post-order recursion）の「後半＝戻りの相」**のように——いちばん深くまで潜って
底（本質）に触れてから、戻りながら各層を**統合**して畳んでいく。
物語の前半に置かれた **伏線** を後半で **回収** するように、これまでの探索・エッセイ・問いを一つにまとめる。

- **順序が要**：先にまとめない。**まず潜って全体像を掴む（発見）→ それから戻りの相で統合する（まとめ）**。
  底に触れて初めて、戻り道で伏線が回収できる
- **伏線＝保持してきた問い**：OVERVIEW §4 の保持論点や各篇の問いが「前半の伏線」。D はそれを後半で回収する
- **C との違い**：C は **外向き**（初学者へ素朴な物語を手渡す）。D は **内向きの総括**
  （pjdhiro の論全体を、戻りの相で一つに畳む）。両者は連携しうる（D で掴んだ全体像を C で物語化する等）
- **自己相似**：この「戻りの相で統合」という方法そのものが、エッセイの主題
  （渦・止揚・スパイラル・分けて分け合う・統合）の**実演**になっている。方法が内容を映す

> 群盲象を評す。一篇は象の一部に触れた手の感触にすぎないが、重なれば輪郭が浮かぶ。
> ——そしてその「手の感触」こそ、論に翻訳する前に保存すべきもの。
> 重なって浮かんだ輪郭を、また素朴な物語に戻して手渡すのが目的C。
> いちばん深くまで潜ってから、戻りながら伏線を回収して一つに畳むのが目的D。

## 運用ポリシー

- **発表用ではない**。論として整っていなくてよい。雑でよい
- 一次の語りを **改変しない**。原文をそのまま `## 原文` に保存する
- **解釈・体系化を急がない**（CLAUDE.md 絶対原則「保持論点を急いで解くな」）。
  気づいたこと・問いは、問いのまま残してよい
- 後から振り返るための軽いタグや「接点（仮）」は付けてよいが、断定しない（`[S]` 推測の温度）
- 1 篇 1 ファイル。命名: `{YYYY-MM-DD}-{slug}.md`
- front matter に最低限のメタ（日付・出典・テーマタグ）を置く
- **[`SYNTHESIS.md`](./SYNTHESIS.md) は「現時点の仮案」を常に最新に保つ**（always-latest）。
  エッセイ追加・新知見・pjdhiro 確定のたびに上書き更新し、古い見当は更新ログに残す（目的D の準備層）

## LLM への読み方の指示

このディレクトリを読むとき、LLM は「正しい結論」を急いで出さない。
pjdhiro が **何を見ているか・どの軸で世界を切っているか** を観察し、
複数篇にまたがって反復する主題・対比・比喩を拾い、
本人がまだ名づけていないものに（仮の）名前を差し出す。

**ただし最重要の禁則（anti-collapse）**:
エッセイを **抽象用語に畳んで終わらせない**。「これは止揚／直交基底／弁証法だ」と
**ラベルを貼った時点で、このエッセイを残した意味（目的B）が死ぬ**。
論への接地（cs/as/ks へのマッピング）は補助線として有用だが、それは**手段**であって主目的ではない。

主目的は、各エッセイが持つ **「とっかかり・喩え・素朴な概念理解・気づきの誘発」** の力を
**取り出して言語化し、損なわずに保存する**こと。読むたびに問うべきは：

- このエッセイは、どの抽象概念への **入口（on-ramp）** になりうるか
- どの **喩え／像** が、初学者の手をつかむか
- 言い切らずに **「あ、そういうことか」** を起こす余白はどこか

→ これを各エッセイの `## 喩えとしての価値（とっかかり）` と、OVERVIEW の
`## 喩え・とっかかりカタログ` に蓄積する。

- **[`SYNTHESIS.md`](./SYNTHESIS.md)**（現時点の仮案・always-latest）：仮説×論文×エッセイの重ね合わせから立てた**全体像の見当**と**伏線台帳**。目的D の準備層
- **[`dialogue/`](./dialogue/)**（対話録・参照用）：pjdhiro ↔ LLM の共構築の対話録。エッセイ（一人称・原文保存）とは別レイヤーで、重ね合わせを支える**参照材料**
