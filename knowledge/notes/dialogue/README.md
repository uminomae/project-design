# notes/dialogue/

pjdhiro と LLM の **対話録**（LLM対話録）を集める参照用レイヤー。

## エッセイ（`notes/` 直下）との違い

| | エッセイ（`notes/*.md`） | 対話録（`notes/dialogue/*.md`） |
|---|---|---|
| 主体 | pjdhiro 一人称 | pjdhiro ↔ Claude の**共構築** |
| 形 | 完成された一人の思考・雑感 | 気づきが**段階的に立ち上がる過程**そのもの |
| 保存 | **原文をそのまま** | 要点を**圧縮・再構成**（話者は明示） |
| 用途 | 思考・価値観の一次記録 | **参照用**（エッセイ／SYNTHESIS の裏付け・補助線） |

## 位置づけ

- ここは **参照（reference）** の置き場。エッセイの代わりではなく、エッセイ群と
  SYNTHESIS（目的D の仮案）の**重ね合わせを支える材料**として使う
- 対話録は共構築ゆえ、Claude 側の発話には推測・誤りが混じりうる。**untrusted 寄りに扱い**、
  pjdhiro が言い切った定義のみを「確定」として扱う（SYNTHESIS §2 の梁に上げるのは pjdhiro 明示分のみ）
- 同じ notes/ の重力圏に置くことで、`OVERVIEW.md` / `SYNTHESIS.md` から参照として引ける

## 配置ポリシー

- 1 対話 1 ファイル。命名: `{YYYY-MM-DD}-{slug}.md`（日付は記録日。対話の実施日が分かれば front matter に併記）
- front matter に source（どの chat か）・話者・主題タグを置く
- 話者は本文で必ず明示（**私**＝pjdhiro ／ **Claude**）
- 末尾に「気づきの要約」を付けてよい（対話録は要点圧縮が許容される）
