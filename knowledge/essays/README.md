# essays/

プロジェクトデザインに **間接的に** 関係しそうな、pjdhiro 自身のエッセイ・投稿・断章を集める場所。

## 位置づけ

`research/`（外部 LLM 調査）や `evidence/`（原典の根拠データ）とは別レイヤー。
ここに集まるのは、調査でも定義でもなく、pjdhiro が日常・体験・連想のなかで書き留めた
**一次の語り**そのものである。SNS 投稿、メモ、随筆など、論として整っていなくてよい。

## なぜ集めるか — 群盲象を評す

一篇ずつは象の鼻や耳に触れた盲人の証言にすぎない。
役に立つかどうかも、その時点では分からない。
だが**集まること**で、別々の局面に触れた手の感触が重なり、
やがて象の輪郭——プロジェクトデザイン論の骨格——が浮かぶかもしれない。

- 急いで解釈・体系化しない（CLAUDE.md 絶対原則「保持論点を急いで解くな」）
- 一次の語りを改変しない。**原文を保存**する
- 後から振り返って洞察の種になりうる接点だけ、軽く（仮説として）メモする

## 配置ポリシー

- 1 篇 1 ファイル。命名: `{YYYY-MM-DD}-{slug}.md`
- front matter に最低限のメタ（日付・出典・テーマタグ）を置く
- 本文は **原文をそのまま** `## 原文` セクションに保存する
- 任意で `## PD との接点（仮）` に、後の洞察収集のためのタグ・問いを残す。
  断定しない。`[S]` 推測仮説の温度で書く
